Write the file `solution.ets`: one ArkUI page for a HarmonyOS app (stage model, ArkTS).

The data for one person is a class `Person` with two fields: `name` (a string) and `score` (a number).

The page is the entry component. It shows a list of three people: Ana with score 3, Bruno with score 5 and Carla with score 1. Each row shows the person's name and score, for example "Ana: 3", and a button "+1".

Pressing the button adds 1 to the score of the person in that row, and the row shows the new score at once. The other rows stay as they are.
