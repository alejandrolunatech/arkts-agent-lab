Write the file `solution.ets`: one ArkUI page for a HarmonyOS app (stage model, ArkTS).

The page is the entry component. It has three tabs labelled "Home", "Search" and "Profile". Each tab has its own content: one line of text, different for each tab. The user changes tab by tapping a label in the tab bar or by swiping.

Outside the tabs, the page shows a line of text with the name of the tab that is open, for example "Current tab: Home". It starts on Home and updates every time the tab changes.
