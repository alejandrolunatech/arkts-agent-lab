Write the file `solution.ets`: one ArkUI page for a HarmonyOS app (stage model, ArkTS).

The page is the entry component. It shows a grid of twelve square tiles in three columns of equal width. Each tile shows its number, from 1 to 12.

- Tapping a tile selects it: its background changes to a different colour.
- Tapping a selected tile unselects it.

Above the grid, a line of text shows how many tiles are selected, for example "Selected: 3". It starts at 0 and updates on every tap.
