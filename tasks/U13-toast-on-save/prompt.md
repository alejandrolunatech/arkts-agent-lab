Write the file `solution.ets`: one ArkUI page for a HarmonyOS app (stage model, ArkTS).

The page is the entry component. It shows two buttons, one under the other:

- "Save": pressing it shows a toast with the text "Saved", a short message over the page that goes away by itself.
- "Delete": pressing it opens a dialog that asks "Delete this item?" and offers two choices, "Cancel" and "Delete". Choosing "Delete" closes the dialog and shows a toast with the text "Deleted". Choosing "Cancel" closes the dialog and nothing else happens.
